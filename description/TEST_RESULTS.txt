### Interpreting Results

**Look for:**
- ✓ High accuracy (>90%)
- ✓ Consistent metrics across models
- ✓ Weight changes between rounds (proves training)
- ✓ Low log loss (near 0)

**Be concerned if:**
- ✗ Accuracy drops between rounds
- ✗ No weight changes (client not training)
- ✗ High log loss (>1)
- ✗ Very imbalanced metrics

## Support & Customization

### Customize Model Paths
Edit at top of `test.py`:
```python
MODEL_DIR = "models"
DATASET_PATH = "dataset"
```

### Customize Feature Columns
Edit `FEATURE_COLS` list in `test.py` to match your data

### Add Custom Metrics
Add to `evaluate_model()` function:
```python
# Your custom metric here
custom_metric = ...
results["custom_metric"] = custom_metric
```

### Test Specific Model
Use the `test_single_model()` function:
```python
test_single_model(
    "models/network_sgd_classifier_round2.joblib",
    "dataset"
)
```
